{%- comment -%} The rest of this world's section, at the foot of every world page. A world page used to end at its own content: the only way from Pokémon to Minecraft was back to /worlds/ and down the page to find it again. The two are in the same rank and belong beside each other, so each page now ends with the others in ITS rank: inside the Core Three you get the other two, inside Primary all of Primary, inside Who I Am the other five. It takes nothing. The page already says which world it is, in the `fan` front-matter key that also drives data-fan, and _data/worlds.yml (written by tools/worlds.py from fandom-data.js) says which rank that world is in and who else is there. So this walks the ranks, finds the one holding this page, and prints its other members. Adding a world to a rank adds it to every sibling strip in that rank, with no page edited. Params: none. It matches on page.url, which Jekyll sets to the page's own permalink verbatim, trailing slash and all, exactly as the href in worlds.yml is written (topbar.html compares the same way). tools/check.py holds the two sides to that: every href in the file is a real page and every world page appears in the file.
